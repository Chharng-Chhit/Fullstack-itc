# Course & TP Structure of Fullstack Web Development

Below is the project-based Course & TP Structure for Fullstack Web Development.

This follows the uploaded structure: Course Session + TP Session + CLO + Chapter Title + Chapter Outline + Project Output. The sample course structure uses weekly Course Session and TP Session format, so this version adapts that format for fullstack web development.

The course focuses on React for frontend, Laravel for backend API, database, frontend/backend integration, and Docker deployment. HTML, CSS, and JavaScript are kept around 30 hours as foundation. MDN covers HTML/CSS/JavaScript foundation topics, React's official docs focus on components, props, state, and interactivity, Laravel docs cover routes/API/authentication, and Docker docs cover Dockerfile and Compose for multi-container apps. (MDN Web Docs)

## Class Information

- **Start Date:** 10-Aug-2026

## Course Main Sessions

|---|---|
