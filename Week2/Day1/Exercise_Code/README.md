# CSS Practice Exercises

These four exercises are based on the visual examples in `CSS Practice (1).pdf`.

## Exercise List

| File | Practice focus |
|---|---|
| `exercise-1-profile.html` | Profile card, image circle, spacing, text alignment, social links |
| `exercise-2-sign-in.html` | Form labels, inputs, checkbox, buttons, and card layout |
| `exercise-3-product-card.html` | Product image area, price, favorite badge, and button |
| `exercise-4-portfolio.html` | Navigation, hero layout, responsive columns, and buttons |

Each HTML file has its own CSS file. Open the HTML file directly in a browser.

## Important Difference from the PDF

The PDF shows target pictures only. It does not include exact text, image files, font files, or written instructions. These starter solutions use simple text, CSS backgrounds, and emoji placeholders so students can practise the layout without downloading assets.

## Student Practice Flow

For each exercise:

1. Open the HTML and CSS files.
2. Identify the main card or page sections.
3. Change one color.
4. Change one spacing value.
5. Change one font size.
6. Resize the browser and check the mobile layout.
7. Add one personal change.

## Beginner Concepts Used

- HTML semantic elements: `header`, `main`, `section`, `article`, `form`, and `footer`
- External CSS files
- Element and class selectors
- Colors and backgrounds
- Fonts and text alignment
- Margin, padding, border, and border radius
- Flexbox
- Simple Grid layout
- Relative and absolute positioning
- Hover and focus states
- Basic media queries

## Submission Checklist

- [ ] All four HTML files open in a browser.
- [ ] Every HTML file links to the correct CSS file.
- [ ] Form controls have visible labels.
- [ ] Buttons and links have visible hover or focus states.
- [ ] Cards do not create unwanted horizontal scrolling.
- [ ] The student changed at least one color and one spacing value in every exercise.
- [ ] The student can explain one CSS property used in each exercise.
